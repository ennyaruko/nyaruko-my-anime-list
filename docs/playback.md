# Просмотр аниме

Кнопка «Смотреть» в детализации открывает `/media/:id/watch`.
Страница использует общий контракт `MediaPlaybackService`: адаптеры API находятся
в `app/integrations`, модели в `entities/media`, экран в `pages/media-watch`.
Компоненты связанного аниме и безопасного Markdown переиспользуются детализацией
и страницей просмотра.

## Конфигурация

Полное содержимое для ручной замены `app-config.json` в Gist:
[app-config.example.json](./app-config.example.json). Существующие настройки
перевода, кадров и разрешения MAL ID сохранены.

`values.yummyApplication` — публичный токен заголовка `X-Application`.
Приватный токен для чтения каталога, плееров и комментариев не требуется и
не включён в приложение. Base64 скрывает строки от простого поиска, но не
является шифрованием и не защищает секреты в браузере.

Адреса кодируются существующим скриптом:

```sh
npm run encode:endpoint -- "https://example.com/embed/:anilistId/:episode"
```

Плейсхолдеры: `:anilistId`, `:shikimoriId`, `:episode`. Для отключения
конкретного плеера задайте ему `default: null` в Gist. Публичный токен можно
заменить его Base64-значением в `values.yummyApplication`.

## Yummyani и сопоставление

[Документация API](https://old.yummyani.me/api/swagger).
Сначала используется точное сопоставление MAL ID через `mal_ids` и `remote_ids`.
При отсутствии связи выполняется ограниченный поиск по названиям AniList:
сравниваются альтернативные названия, год, формат и количество эпизодов.
Неоднозначные результаты отклоняются. Подтверждённое соответствие кешируется
на 7 дней, отсутствие соответствия — на час; ошибки сети не кешируются как
отсутствие аниме.

Плееры группируются по провайдеру и озвучке; номер серии берётся из `number`,
а не из технического `index`. Смена плеера выбирает его первую озвучку.
Порядок просмотра сохраняется целиком, включая прошлые сезоны. Текущее аниме
выделено как некликабельный пункт. Остальные пункты открывают
страницу просмотра через их внешний MAL ID; если связи нет, показывается
сообщение вместо перехода на случайное аниме.

Комментарии доступны для чтения: сортировка, загрузка следующих страниц,
раскрытие ответов. HTML пользователя проходит очистку существующим Markdown
компонентом. Голосование и публикация комментариев не подключены к аккаунту AniList.

## Серии и резервные плееры

При прогрессе 2 выбирается серия 3. Переход с 3 на 6 записывает прогресс 3;
пропущенные серии автоматически просмотренными не считаются. Переход назад,
смена языка, плеера или озвучки прогресс не меняют. Запись выполняется через
существующее действие AniList; при ошибке переход не выполняется, можно повторить.
Последняя серия сама по себе не отмечается просмотренной: без следующего
перехода iframe не сообщает достоверное завершение просмотра.

При ошибке каталога или отсутствии подходящих видео включается резервный режим:
RU — Kodik без выбора серий и синхронизации; EN — настроенные плееры с выбором
серий и синхронизацией. Заголовок и связанное берутся из AniList.
Резервный режим также можно включить вручную, если API работает, но сам iframe
не воспроизводит видео. Ошибку воспроизведения внутри чужого iframe браузер
не позволяет надёжно определить автоматически.

Встраивание ограничено HTTPS. По умолчанию используется sandbox без всплывающих
окон и перехода верхней страницы. Исключения — Anixo и Vidnest, которые блокируют работу
в sandbox: для их EN-плееров sandbox отключён. Доступность конкретного видео, географические ограничения и разрешение
на встраивание зависят от внешнего плеера.

Размеры резервного Kodik передаются в пикселях по фактическому размеру контейнера:
его обёртка некорректно обрабатывает `100%`. Изменение ширины окна обновляет размеры.
Длинные комментарии сворачиваются до 160 px; общий компонент используется также
в отзывах. При ошибке загрузки аватара показывается стандартная иконка отсутствующего изображения.
