# Конфигурация адресов через GitHub Gist

Подключён Gist с файлом **app-config.json**: [актуальный JSON](https://gist.githubusercontent.com/Nyar1othotep/db157de01d95d0ea10e5d7dd236462ac/raw/app-config.json). Формат также сохранён в [app-config.example.json](./app-config.example.json).

```json
{
  "version": 1,
  "endpoints": {
    "translation": "https://translate.googleapis.com/translate_a/single"
  }
}
```

Для обновляемой конфигурации используется Raw-ссылка без закреплённой ревизии:

`https://gist.githubusercontent.com/<username>/<gist-id>/raw/app-config.json`

Ссылка задана в `GIST_CONFIG_URL` в `src/app/config/remote-endpoints.ts`. Если убрать её (задать `undefined`), будет использоваться встроенный адрес перевода без запросов к GitHub.

## Контракт

- `version`: версия схемы, сейчас `1`.
- `endpoints`: словарь именованных HTTPS-адресов без логина и пароля в URL. Ключ `translation` используется переводчиком.
- Для будущих интеграций можно добавлять другие ключи в `endpoints`; резолвер не зависит от перевода. Плееры сейчас не реализованы.
- Это публично доступная клиенту конфигурация: токены и секреты в неё не помещаются. Код из Gist не исполняется.
- Адрес `translation` должен поддерживать параметры `client=gtx`, `sl=auto`, `tl=ru`, `dt=t`, `q` и ответ формата Google Translate из примера. Заменяемый сервер должен разрешать браузерные CORS-запросы. Смена протокола API потребует другого адаптера, одной замены URL недостаточно.

Конфигурация запрашивается при первом переводе и кешируется в памяти на 10 минут. Параллельные потребители используют один запрос. При следующем обращении после TTL адреса обновляются; при ошибке сети, неизвестной версии или невалидном JSON сохраняется последняя валидная конфигурация, а до её загрузки — встроенные адреса. Повторная попытка возможна через 30 секунд. Таймаут Gist — 8 секунд.

## Перевод

Автоперевод включается в меню пользователя и сохраняется в localStorage. Включён: описание и отзывы новой страницы открываются в Ru; выключен: в En. En показывает исходный текст, Ru запускает перевод на русский с автоопределением исходного языка. Ручной выбор независим для описания и секции отзывов и сбрасывается при смене аниме или настройки автоперевода.

Переводятся текст описания, заголовки и текст отзывов. Ссылки, картинки, авторы, оценки и разметка сохраняются. Длинные тексты делятся по границам слов с учётом длины URL; одновременно выполняется не более двух запросов. Переводы кешируются в памяти приложения, не сохраняются в IndexedDB. Возврат в En отменяет ненужные запросы. При ошибке сервиса остаётся оригинал и доступен повтор. Доступность и ограничения endpoint без API-ключа определяет провайдер.
